# Componentes reutilizables

## Principio
Un componente se vuelve compartido únicamente cuando dos o más módulos lo utilizan realmente.

## Sugeridos
- Button
- Input
- Select
- Textarea
- Badge
- Modal
- Card
- FormField
- SearchField
- DateField
- MoneyField
- DataTable
- TablePagination
- LoadingState
- EmptyState
- ErrorMessage
- ConfirmDialog
- PageHeader
- SummaryCard

## Reglas
- No duplicar componentes.
- No construir un design system completo por anticipado.
- Mantener props simples.
- Un componente debe tener una responsabilidad.
- Los formularios específicos permanecen dentro de su módulo.

## Sistema visual vigente

- Estética contemporánea inspirada en la claridad de ChatGPT y Apple, sin
  replicar sus marcas o elementos propietarios.
- Fondo general neutro con gradientes verde azulado de muy baja intensidad.
- Navegación lateral clara y superficies translúcidas con bordes sutiles,
  desenfoque moderado y sombras contenidas.
- Verde azulado oscuro limitado a identidad, foco, estado activo y acciones
  principales.
- Usar solo dos categorías tipográficas: la familia sans serif del sistema
  para toda la interfaz y una monoespaciada del sistema para códigos,
  identificadores y datos tabulares.
- Priorizar espacio en blanco, jerarquías compactas y controles de acción con
  forma de píldora.
- No mostrar números de fase, avisos de demostración ni referencias al estado
  de desarrollo dentro de la interfaz.
- Mantener los colores de alerta reservados para estados semánticos.
